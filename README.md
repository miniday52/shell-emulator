# Эмулятор командной оболочки ОС — вариант 22

Практическая работа №1 по дисциплине «Конфигурационное управление»
(РТУ МИРЭА, группа ИКБО-50-25).

## 1. Общее описание

Консольное (CLI) приложение на Python 3, эмулирующее работу в командной
строке UNIX-подобной ОС. Эмулятор работает с **виртуальной файловой
системой (VFS)**, загружаемой из XML-файла. Все операции выполняются
только в памяти: исходный XML-файл никогда не изменяется.

Возможности:

* приглашение к вводу строится из реальных данных ОС:
  `username@hostname:~$`;
* простой парсер — ввод разделяется на команду и аргументы по пробелам;
* сообщения об ошибках: неизвестная команда, неверные аргументы и опции;
* параметры командной строки: путь к VFS и путь к стартовому скрипту,
  отладочный вывод всех параметров при запуске;
* стартовый скрипт: команды выполняются последовательно, ошибочные
  строки пропускаются, ввод и вывод отображаются как диалог;
* VFS из XML-файла, двоичные данные в base64; VFS по умолчанию в
  памяти, если путь не указан;
* команды: `ls`, `cd`, `pwd`, `uptime`, `uniq`, `rm`, `exit`
  и служебная команда `vfs-info`.

Внешних зависимостей нет — используется только стандартная библиотека
Python (версия 3.8 и новее).

## 2. Описание функций и настроек

### 2.1. Параметры командной строки

| Параметр        | Описание                                            |
|-----------------|-----------------------------------------------------|
| `--vfs PATH`    | путь к XML-файлу VFS; без него создаётся VFS по умолчанию |
| `--script PATH` | путь к стартовому скрипту                           |
| `-h`, `--help`  | справка по параметрам                               |

При запуске выводятся все параметры в формате `ключ = значение`:

```
[config] Параметры эмулятора:
[config]   script = examples/scripts/stage4.txt
[config]   vfs = examples/vfs/deep.xml
```

Коды возврата: `0` — штатное завершение (или код из `exit N`),
`1` — ошибка загрузки VFS или чтения скрипта, `2` — неверные параметры.

### 2.2. Стартовый скрипт

Текстовый файл (UTF-8), по одной команде в строке.

* Пустые строки и строки, начинающиеся с `#`, игнорируются.
* Перед каждой командой печатается приглашение и сама команда, затем её
  вывод — как при диалоге с пользователем.
* Ошибочная строка пропускается: печатается сообщение об ошибке и
  `[script] <файл>:<номер строки>: line skipped`; выполнение
  продолжается.
* Команда `exit` завершает эмулятор. Если скрипт закончился без `exit`,
  эмулятор переходит в интерактивный режим.

### 2.3. Формат VFS (XML)

```xml
<vfs name="demo" home="/home/user">
  <dir name="home">
    <dir name="user">
      <file name="hello.txt">Hello!</file>
      <file name="logo.bin" encoding="base64">iVBORw0KGgo=</file>
    </dir>
  </dir>
</vfs>
```

| Элемент / атрибут      | Назначение                                     |
|------------------------|------------------------------------------------|
| `<vfs>`                | корневой каталог; обязательный корневой элемент |
| `name`                 | имя VFS (по умолчанию — имя файла)              |
| `home`                 | домашний каталог, отображается как `~` (по умолчанию `/`) |
| `<dir name="...">`     | каталог; может содержать `dir` и `file`         |
| `<file name="...">`    | файл; текст элемента — содержимое (UTF-8)       |
| `encoding="base64"`    | содержимое файла закодировано в base64          |

Многострочное текстовое содержимое, начинающееся с переноса строки,
автоматически избавляется от общего отступа.

Ошибки загрузки (эмулятор завершается с кодом 1): файл не найден,
неверный XML, корневой элемент не `<vfs>`, неизвестный элемент,
пустое/недопустимое/повторяющееся имя, неверный base64, отсутствующий
домашний каталог.

VFS по умолчанию (без `--vfs`): `/home/user/readme.txt`,
`/etc/hostname`, пустой `/tmp`; домашний каталог `/home/user`.

### 2.4. Команды

Пути могут быть абсолютными (`/etc`), относительными (`projects/app`),
содержать `.`, `..` и `~` (домашний каталог). Короткие опции можно
объединять (`-la`), `--` завершает список опций.

| Команда | Описание |
|---------|----------|
| `ls [-l] [-a] [путь...]` | содержимое каталога (по умолчанию текущего), отсортированное по имени. `-l` — подробный формат (тип/права, размер в байтах или число элементов каталога), `-a` — показывать `.` и `..`. Для нескольких каталогов выводятся заголовки `путь:`. Для файла выводится его имя. |
| `cd [путь]` | смена текущего каталога. Без аргумента или `~` — домашний каталог, `cd -` — предыдущий каталог. Ошибки: нет такого пути, не каталог, лишние аргументы. |
| `pwd` | абсолютный путь текущего каталога. |
| `uptime [-p] [-s]` | время работы эмулятора в формате `uptime(1)`: ` 14:03:12 up 5 min,  1 user,  load average: ...`. `-p` — в удобочитаемом виде (`up 1 hour, 5 minutes`), `-s` — время запуска (`2026-10-10 14:00:00`). |
| `uniq [-c] [-d] [-u] [-i] файл` | выводит файл, схлопывая соседние одинаковые строки. `-c` — префикс с числом повторов, `-d` — только повторяющиеся строки, `-u` — только уникальные, `-i` — без учёта регистра. |
| `rm [-r\|-R] [-f] [-d] [-v] путь...` | удаление файлов и каталогов (только в памяти). Каталог удаляется с `-r`/`-R` (рекурсивно) или `-d` (только пустой). `-f` — не сообщать об отсутствующих путях, `-v` — печатать удалённое. Запрещено удалять `/`, `.`/`..`, текущий каталог и его родителей. |
| `exit [код]` | завершение эмулятора с кодом возврата (по умолчанию 0). |
| `vfs-info` | служебная: имя VFS, источник, домашний каталог, число каталогов/файлов и объём данных. |

Все сообщения об ошибках начинаются с `error:`; ошибка не прерывает
интерактивный режим.

## 3. Сборка, запуск и тесты

Сборка не требуется — нужен только Python 3.8+.

Запуск эмулятора:

```bash
./run.sh --vfs examples/vfs/deep.xml          # Linux / macOS
```

```bat
run.bat --vfs examples\vfs\deep.xml           :: Windows
```

```bash
PYTHONPATH=src python3 -m emulator --help     # напрямую
```

Запуск модульных тестов (43 теста):

```bash
python -m unittest discover -s tests -t . -v
```

или `make test`.

Скрипты ОС для тестирования (каталог `scripts/`):

| Скрипт | Что проверяет |
|--------|---------------|
| `test_params.bat` / `.sh` | все параметры командной строки, отсутствующий скрипт, неверный параметр (этап 2) |
| `test_vfs.bat` / `.sh` | VFS по умолчанию, минимальная, несколько файлов, вложенность 3+ уровня, ошибки загрузки (этап 3) |
| `test_commands.bat` / `.sh` | стартовые скрипты `stage4.txt` и `stage5.txt` со всеми командами (этапы 4–5) |

Стартовые скрипты эмулятора (`examples/scripts/`): `stage2.txt`,
`stage3.txt`, `stage4.txt`, `stage5.txt`.

## 4. Примеры использования

### Интерактивный режим (этап 1)

```
$ ./run.sh
[config] Параметры эмулятора:
[config]   script = <не задан>
[config]   vfs = <не задан>
rusla@Ruslan:~$ foo bar
error: foo: command not found
rusla@Ruslan:~$ exit abc
error: exit: abc: numeric argument required
rusla@Ruslan:~$ exit 5
```
